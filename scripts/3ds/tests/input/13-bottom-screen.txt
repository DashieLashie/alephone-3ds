# Stage 7 (docs/3ds/STAGE7.md): the bottom screen in game. Run once per
# Bottom Screen setting (<graphics bottom_screen="0|2">: HUD + Map, Classic).
# HUD + Map: the HUD in rows 0-79, the map in rows 80-239. With the main map
# closed, the map zoom keys (D-Pad Up in, Down out) zoom the bottom map
# between 1 and 3 (default 2); with it open they zoom the main map. Taps on
# the bottom screen do nothing (only a drag looks).
